# OpenRouter 助手 (USD→CNY + 翻译)

Chrome / Edge 浏览器扩展，专为 [OpenRouter.ai](https://openrouter.ai) 用户打造：

- **美元→人民币**：全站价格自动转换为人民币显示
- **术语翻译**：界面英文术语精准翻译为中文（不破坏页面结构）

## 安装

### Chrome Web Store
[Chrome 商店链接（待发布）](https://chromewebstore.google.com/)

### Edge Add-ons
[Edge 商店链接（待发布）](https://microsoftedge.microsoft.com/addons/)

### 手动安装
1. 下载本仓库代码
2. 打开 chrome://extensions/（Edge: edge://extensions/）
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择项目目录
