隐私权政策

最后更新日期：2025 年 8 月 17 日

概述

「OpenRouter 助手 (USD→CNY + 翻译)」（以下简称「本扩展」）尊重并保护用户隐私。本扩展不会收集、存储、传输或分享任何用户个人信息。

数据收集

本扩展不收集任何用户数据，包括但不限于：

  • 个人身份信息（姓名、邮箱、地址等）
  • 浏览历史记录
  • 网站内容或用户活动
  • 位置信息
  • 财务或付款信息

本地存储

本扩展使用 Chrome 的 storage.local API 仅在用户设备本地存储以下数据：

  • 汇率缓存：USD/CNY 汇率数值及更新时间戳，用于减少 API 请求频率，每 6 小时自动刷新
  • 用户偏好：翻译功能的开启/关闭状态

上述数据仅保存在用户本地设备上，不会上传至任何服务器或与第三方共享。

网络请求

本扩展仅向以下三个公开免费汇率 API 发起请求，用于获取实时 USD/CNY 汇率：

  • qt.gtimg.cn（腾讯行情）
  • open.er-api.com
  • api.frankfurter.app

请求中不包含任何用户信息，仅获取汇率数值。三个数据源互为备用，以确保服务可用性。

第三方服务

本扩展不与任何第三方服务共享数据，不使用任何分析工具或广告 SDK。

内容脚本

本扩展的内容脚本仅在 openrouter.ai 域名下运行，功能为：

  • 将页面上的美元价格转换为人民币显示
  • 将界面英文术语翻译为中文

内容脚本不会读取、修改或传输页面上的任何用户数据。

权限说明

  • storage：用于本地缓存汇率和用户偏好设置
  • host_permissions：仅用于请求上述三个汇率 API 的数据

儿童隐私

本扩展不针对 13 岁以下儿童，也不会有意收集儿童的个人信息。

隐私政策变更

如本隐私政策发生变更，我们将通过扩展更新日志通知用户。建议用户定期查阅本政策。
