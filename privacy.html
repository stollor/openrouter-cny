Privacy Policy

Last updated: August 17, 2025

Overview

"OpenRouter Assistant (USD→CNY + Translation)" (hereinafter referred to as "this extension") respects and protects user privacy. This extension does not collect, store, transmit, or share any personal user information.

Data Collection

This extension does not collect any user data, including but not limited to:

  • Personally identifiable information (name, email, address, etc.)
  • Browsing history
  • Website content or user activity
  • Location information
  • Financial or payment information

Local Storage

This extension uses Chrome's storage.local API to store the following data locally on the user's device only:

  • Exchange rate cache: USD/CNY exchange rate value and update timestamp, used to reduce API request frequency, automatically refreshed every 6 hours
  • User preferences: Translation feature on/off state

The above data is stored only on the user's local device and is never uploaded to any server or shared with third parties.

Network Requests

This extension only sends requests to the following three public free exchange rate APIs to obtain real-time USD/CNY exchange rates:

  • qt.gtimg.cn (Tencent Finance)
  • open.er-api.com
  • api.frankfurter.app

No user information is included in these requests — only exchange rate values are fetched. The three data sources serve as backups for each other to ensure service availability.

Third-Party Services

This extension does not share data with any third-party services and does not use any analytics tools or advertising SDKs.

Content Scripts

This extension's content scripts only run on the openrouter.ai domain, with the following functions:

  • Converting USD prices on the page to CNY display
  • Translating English UI terminology to Chinese

Content scripts do not read, modify, or transmit any user data from the page.

Permission Justification

  • storage: Used to locally cache exchange rates and user preference settings
  • host_permissions: Only used to request data from the three exchange rate APIs mentioned above

Children's Privacy

This extension is not directed at children under 13 years of age and does not knowingly collect personal information from children.

Privacy Policy Changes

If this privacy policy changes, we will notify users through the extension update log. Users are encouraged to review this policy periodically.
